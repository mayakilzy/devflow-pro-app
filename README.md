A comprehensive developer productivity platform that extends DevFlow Lite with additional features for modern development teams.

## Features

- **Code Snippet Manager**: Save, organize, and search code snippets with syntax highlighting
- **Bug Tracker**: Track bugs with severity levels, statistics, and visual charts
- **Sprint Kanban Board**: Drag-and-drop task management with velocity tracking
- **Team Mood Tracker**: Monitor team morale with daily check-ins and trend analysis
- **Documentation Finder**: Search and bookmark library/API documentation
- **CI/CD Monitor**: Track build statuses with real-time updates and alerts
- **Knowledge Base**: Create and organize technical documentation with markdown support

## Tech Stack

- **Frontend**: Next.js 16, React 18, TypeScript
- **Styling**: Tailwind CSS with dark mode support
- **Charts**: Recharts for data visualization
- **Icons**: Lucide React
- **Drag & Drop**: @hello-pangea/dnd
- **Markdown**: Marked.js
- **Date Handling**: date-fns
- **Audio**: Web Audio API

## Quick Start

1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Usage

- Use the sidebar to navigate between different features
- Press `Cmd+K` (Mac) or `Ctrl+K` (Windows) to open the command palette
- All data is saved to localStorage and persists between sessions
- Customize your experience with theme settings and keyboard shortcuts
