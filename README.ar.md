# DevFlow Pro

[![رخصة: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=flat&logo=typescript&logoColor=white)](https://www.typescriptlang.org/)
[![Next.js](https://img.shields.io/badge/Next.js-black?style=flat&logo=next.js&logoColor=white)](https://nextjs.org/)

منصة شاملة لزيادة إنتاجية المطورين تجمع كل الأدوات التي تحتاجها في مكان واحد. DevFlow Pro يمتد DevFlow Lite بميزات إضافية للتعاون الفريق وزيادة الإنتاجية.

## الميزات

- **مديم الأكواد**: حفظ وتنظيم البحث عن الأكواد مع تمييز الصياغة
- **متعقب الأخطاء**: تتبع وتصوير الأخطاء مع مستويات الأهمية والإحصائيات
- **لوحة كانبان للسباقات**: واجهة سحب وإفلات للتخطيط السريع
- **متعقب مزاج الفريق**: مراقبة معنويات الفريق مع التحقق اليومي
- **موجّه التوثيق**: البحث وحفظ التوثيق التقني
- **مراقب CI/CD**: تتبع حالات البناء وتقدم النشر
- **قاعدة المعرفة**: إنشاء وتنظيم التوثيق التقني
-لوحة التحكم**: نظرة عامة على جميع الوحدات مع الإحصائيات السريعة

## التقنية المستخدمة

- **الواجهة الأمامية**: Next.js 16, React 18, TypeScript
- **التصميم**: Tailwind CSS مع الوضع المظلم
- **الرسوم البيانية**: Recharts
- **السحب والإفلات**: @hello-pangea/dnd
- **الماك داون**: marked
- **الأيقونات**: Lucide React
- **التواريخ**: date-fns

## البداية السريعة

1. استنسخ المستودع
2. قم بتثبيت الاعتمادات: `npm install`
3. ابدأ خادم التطوير: `npm run dev`
4. افتح [http://localhost:3000](http://localhost:3000) في متصفحك

## البنية

يتبع DevFlow Pro نمط البنية المفردة حيث تكون جميع المكونات والأدوات وإدارة الحالة داخل `src/app/page.tsx`. هذا النبسط يبسط الكود ويجعله أسهل في الفهم والصيانة.

يتم حفظ جميع البيانات في localStorage وحفظها تلقائياً عند التغيير. يستخدم التطبيق نمط React 19 lazy useState لتحميل البيانات بكفاءة.

## الاختصارات

- `Cmd/Ctrl + K`: فتح لوحة الأوامر
- `Cmd/Ctrl + N`: إنشاء عنصر جديد (يعتمد على السياق)
- `Esc`: إغلاق النوافذ والحوارات
