منصة شاملة لزيادة إنتاجية المطورين تجمع الأدوات الأساسية في تطبيق واحد.

## المميزات

- **مديم الأكواد**: حفظ وتنظيم وأكواد مع تمييز الصياغة
- **متعقب الأخطاء**: تتبع الأخطاء مع مستويات الأهمية والإحصائيات والرسوم البيانية
- **لوحة كانبان للمشاريع**: إدارة المهام بسحب وإفلات مع تتبع السرعة
- **متعتابع مزاج الفريق**: تسجيل المزاج اليومي مع الاتجاهات والتحليلات
- **موجّه التوثيق**: البحث وحفظ التوثيق التقني
- **مراقب CI/CD**: تتبع حالة البناء الفوري مع التنبيهات
- **قاعدة المعرفة**: إنشاء وتنظيم التوثيق التقني بدعم ماركداون

## التقنيات المستخدمة

- **الواجهة الأمامية**: Next.js 16, React 18, TypeScript
- **التصميم**: Tailwind CSS بدعم الوضع المظلم
- **الرسوم البيانية**: Recharts للتصور البياني
- **الأيقونات**: Lucide React
- **ماركداون**: Marked.js للعرض
- **السحب والإفلات**: @hello-pangea/dnd
- **التواريخ**: date-fns
- **الصوت**: Web Audio API للإشعارات

## البداية السريعة

1. استنسخ المستودع
2. قم بتثبيت الاعتمادات: `npm install`
3. ابدأ خادم التطوير: `npm run dev`
4. افتح [http://localhost:3000](http://localhost:3000) في متصفحك

## الاستخدام

- استخدم الشريط الجانبي للتنقل بين الوحدات المختلفة
- اضغط `Cmd+K` (ماك) أو `Ctrl+K` (ويندوز) لفتح لوطة الأوامر
- يتم حفظ جميع البيانات تلقائيًا في localStorage
- تخصيص تجربتك في لوحة الإعدادات
