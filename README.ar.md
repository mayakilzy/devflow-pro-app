منصة شاملة لزيادة إنتاجية المطورين تمتد من ديفلو لايت بميزات إضافية للفرق الحديثة.

## الميزات

- **مديم الأكواد**: حفظ وتنظيم وأكواد مع تمييز الصياغة
- **تتبع الأخطاء**: تتبع الأخطاء مع مستويات الأهمية والإحصائيات والرسوم البيانية
- **لوحة كانبان للسباقات**: إدارة المهام بسحب وإفلات مع تتبع السرعة
- **تتبع مزاج الفريق**: مراقبة معنويات الفريق مع التحقق اليومي وتحليل الاتجاهات
- **مستندات البحث**: البحث وحفظ المستندات البرمجية وواجهات برمجة التطبيقات
- **مراقبة CI/CD**: تتبع حالات البناء مع التحديثات الفورية والتنبيهات
- **قاعدة المعرفة**: إنشاء وتنظيم الوثائق التقنية بدعم ماركداون

## التقنية المستخدمة

- **الواجهة الأمامية**: Next.js 16, React 18, TypeScript
- **التصميم**: Tailwind CSS بدعم الوضع المظلم
- **الرسوم البيانية**: Recharts للتصور البياني
- **الأيقونات**: Lucide React
- **السحب والإفلات**: @hello-pangea/dnd
- **ماركداون**: Marked.js
- **معالجة التواريخ**: date-fns
- **الصوت**: Web Audio API

## البداية السريعة

1. استنسخ المستودع
2. قم بتثبيت الاعتمادات: `npm install`
3. ابدأ خادم التطوير: `npm run dev`
4. افتح [http://localhost:3000](http://localhost:3000) في متصفحك

## الاستخدام

- استخدم الشريط الجانبي للتنقل بين الميزات المختلفة
- اضغط `Cmd+K` (ماك) أو `Ctrl+K` (ويندوز) لفتح لوحة الأوامر
- يتم حفظ جميع البيانات في localStorage وتستمر بين الجلسات
- تخصيص تجربتك بإعدادات السمات والاختصارات المفاتيح
