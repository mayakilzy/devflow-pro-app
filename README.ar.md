منصة شاملة لزيادة إنتاجية المطورين تجمع الأدوات الأساسية في تطبيق واحد.

## الميزات

- **مديم الأكواد**: حفظ وتنظيم البحث عن الأكواد مع تمييز الصيغة
- **متعقب الأخطاء**: تتبع الأخطاء مع مستويات الخطورة والإحصائيات والرسوم البيانية
- **لوحة كانبان للمشاريع**: إدارة المهام بسحب وإفلات مع تتبع السرعة
- **متعقب مزاج الفريق**: مراقبة رفاهية الفريق مع فحص المزاج والاتجاهات
- **موجّه الوثائق**: البحث عن وتخزين الوثائق التقنية
- **مراقب CI/CD**: تتبع حالات البناء والبيئات
- **قاعدة المعرفة**: إنشاء وتنظيم الوثائق التقنية بدعم ماركداون

## التقنية المستخدمة

- **الواجهة الأمامية**: Next.js 16, React 18, TypeScript
- **التصميم**: Tailwind CSS بدعم الوضع المظلم
- **الرسوم البيانية**: Recharts للتصور البياني
- **الأيقونات**: Lucide React
- **السحب والإفلات**: @hello-pangea/dnd
- **ماركداون**: Marked.js
- **التواريخ**: date-fns
- **الصوت**: Web Audio API

## البداية السريعة

1. استنسخ المستودع
2. قم بتثبيت الاعتماديات: `npm install`
3. ابدأ خادم التطوير: `npm run dev`
4. افتح [http://localhost:3000](http://localhost:3000) في متصفحك

## الاستخدام

- استخدم الشريط الجانبي للتنقل بين الأقسام المختلفة
- اضغط `Cmd+K` (ماك) أو `Ctrl+K` (ويندوز) لفتح لوطة الأوامر
- يتم حفظ جميع البيانات تلقائيًا في التخزين المحلي للمتصفح
- تخصيص تجربتك في لوحة الإعدادات
