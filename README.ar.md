منصة شاملة لزيادة إنتاجية المطورين تتوسع من DevFlow Lite مع 7 ميزات قوية لتبسيط سير عمل التطوير.

## الميزات

- **مديم الأكواد**: حفظ وتنظيم البحث عن الأكواد مع تمييز الصياغة ودعم ماركداون
- **متعقب الأخطاء**: تتبع الأخطاء مع مستويات الأهمية، رسوم بيانية للإحصائيات، وإشعارات فورية
- **لوحة كانبان للسباقات**: إدارة المهام بسحب وإفلات مع تتبع السرعة
- **متعتابع مزاج الفريق**: تدوين المزاج اليومي مع الاتجاهات والتحليلات
- **موجّه الوثائق**: البحث عن وتعليق الوثائق التقنية
- **مراقب CI/CD**: تتبع حالة البناء الفعلية مع الإشعارات
- **قاعدة المعرفة**: إنشاء وتنظيم المقالات التقنية بدعم ماركداون

## التقنية المستخدمة

- **الواجهة الأمامية**: Next.js 16, React 18, TypeScript
- **التصميم**: Tailwind CSS مع الوضع المظلم
- **الرسوم البيانية**: Recharts
- **الأيقونات**: Lucide React
- **السحب والإفلات**: @hello-pangea/dnd
- **ماركداون**: Marked
- **التواريخ**: date-fns
- **الصوت**: Web Audio API

## البداية السريعة

1. استنسخ المستودع
2. قم بتثبيت الاعتماديات: `npm install`
3. ابدأ خادم التطوير: `npm run dev`
4. افتح [http://localhost:3000](http://localhost:3000) في متصفحك

## حفظ البيانات

تخزن جميع البيانات في localStorage وتستمر بين الجلسات. التطبيق يشمل:

- وظيفة الحف التلقائي (مؤقت 500ms)
- تصدير/استيراد البيانات كـ JSON
- خيار إعادة تعيين البيانات

## اختصارات لوحة المفاتيح

- `Cmd/Ctrl + K`: فتح لوطة الأوامر
- `Cmd/Ctrl + N`: إنشاء عنصر جديد
- `Esc`: إغلاق النوافذ/الحوارات
